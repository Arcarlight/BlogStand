# 站内字体来源与许可

站点只分发经过裁剪的子集（都转成了 `woff2`），放在 `static/fonts/`。
下面记录每一份的来源、裁剪方式和许可，方便日后核对。

| 文件 | 字体名 | 用途 | 大小 | 字形数 | 许可 / fsType |
| --- | --- | --- | --- | --- | --- |
| `simsun12-pixel.woff2` | SimSun12 Pixel | 汉字、标点、拉丁 | 689.9 KB | 28547 | © ZHONGYI Electronic Co. 2001, 2020, 2022；**fsType = 8**（Editable，允许嵌入） |
| `msgothic12-jp-pixel.woff2` | MSGothic12 JP Pixel | 平假名 / 片假名 / 半角片假名 | 4.3 KB | 242 | 从 MS Gothic (`msgothic.ttc`) 12ppem 点阵提取；fsType = 8 |
| `mona12emoji.woff2` | Mona12 Emoji | emoji（单色） | 55 KB | 1704 | **SIL OFL 1.1**，Copyright (c) 2025 Monad ABXY |
| `vonwaon-12px.woff2` | VonwaonBitmap 12px | 备选汉字点阵（默认不用） | 95 KB | 2201 | Created by Haoyu Qiu. **No rights reserved.**（公有领域） |

四份都是 12px 栅格：`unitsPerEm` 换算下来 1 个设计像素正好是整数个单位
（宋体 / MS Gothic 是 1536 ÷ 128，Vonwaon 和 Mona 是 1200 ÷ 100），
所有坐标都在网格上、没有曲线段。所以只要满足

```
字号(CSS px) × devicePixelRatio = 12 的整数倍
```

方块就落在像素网格上。字号由 `layouts/_partials/head.html` 里的内联脚本按 DPR 算好。

## 1. SimSun12-Pixel（汉字主力）

用 `fontTools` 从 Windows 系统字体 **宋体（SimSun, simsun.ttc）** 的内嵌 12ppem
点阵（`EBDT`/`EBLC`）里逐字形导出，再画成方格轮廓（`glyf`）做成字体。

**生成脚本在仓库里：`tools/build-pixel-font.py`**（2026-09-13 补上的，
在这之前脚本不在仓库、字体是个手挑的子集）。命令：

```sh
pip install fonttools brotli pillow
python tools/build-pixel-font.py            # 全量：宋体 12ppem 点阵里的 28421 个字形
python tools/build-pixel-font.py --set site # 只做站点现在用到的字（~60 KB）
```

- 版权串：`© Copyright ZHONGYI Electronic Co. 2001, 2020, 2022`
- 版本：`Version 5.24`
- `OS/2.fsType = 8` → `Editable`，允许嵌入与再分发
- 覆盖：宋体 12ppem 那档点阵里的**全部 28421 个字形**，加上原字体里几个
  宋体点阵没有、当初用轮廓补的字，合计 28547 个（原字体 28515 个字形）

> ⚠️ 只保留 `glyf` 是必须的：`pyftsubset` 无法保留 `EBDT`/`EBLC`，
> 直接裁剪会退化成纯轮廓字体，点阵就没了。所以走的是「解出点阵 → 重画成方格轮廓」
> 这条路，得到的每份字形都是 12×12 的整格方块。
> 成品自检：28522 个非空字形里，**不在格点上的坐标 0 个、曲线点 0 个**。

> ⚠️ **2026-09-13 为什么要改成全量**：原来只收了 2339 个字，是手挑的子集。
> 结果站点侧栏里「斗智斗**勇**」的「勇」不在子集里，浏览器就**静默地**掉到字体栈末尾的
> 系统宋体上 —— 字号一样，但那是抗锯齿轮廓，混在一行里一眼就看出发虚。
> 当时逐字查了一遍，站点文本里有 6 个字掉下去：`允 勇 恢 栅 汁 矢`（宋体点阵里有，只是没提取）
> + `⚠ 〜 ・ ️ ･ 🍤`（宋体点阵里也没有，靠 MS Gothic / Mona 兜底）。
> 全量之后，站点文本的覆盖率是 100%。

> ⚠️ **别只按「宋体点阵里有」来筛字**：ASCII 字母、数字和 `»«©½` 这类西文标点
> **不在**宋体的 12ppem 点阵里（原字体里那部分是当初用轮廓补的）。第一版全量脚本
> 按「必须有点阵」过滤，把这 115 个字符全丢了 —— 全站英文都会掉字体。
> 脚本现在的做法是：原字体已有的字一律保留，只有**新增**的字才要求宋体有点阵。

> ⚠️ **体积换覆盖率的取舍**：全量 690 KB，是原来 60 KB 的 11 倍。首页现在总传输
> 约 505 KB，换成全量后约 1.19 MB（字体占 58%），而且它在 `head.html` 里是
> `preload` 的，属于首屏关键路径。GitHub Pages 的静态资源是 `Cache-Control: max-age=600`，
> 冷缓存下这 690 KB 要实打实下（之后靠 ETag 协商，命中就是 304）。
> 脚本也支持分块（`--chunks 4` + `unicode-range`，平时只下 60 KB 那块），
> 2026-09-13 站长选了单文件全量，所以现在是单文件。

## 2. MSGothic12 JP Pixel（日文假名）

同样方式从 **MS Gothic（`msgothic.ttc`）** 的 12ppem 点阵提取，只取假名那 242 个字，
再用 CSS `unicode-range` 按字符路由：

```css
unicode-range: U+301C, U+3040-30FF, U+FF61-FF9F;
```

不需要给 HTML 加 `lang` 标记。注意 MS Gothic 的 12px 点阵缺少 14 个假名
（`ゔゕゖ゗゘ ゙゚ ゟ ゠ ヷヸヹヺ ヿ`），字体栈末尾挂了系统 `SimSun` 兜底。

## 4. VonwaonBitmap 12px（备选）

`hugo.toml` 里 `pixelFontFile = "vonwaon"` 可切换成这份（默认用 `simsun12`）。

- 版权：`Created by Haoyu Qiu. No rights reserved.`
- 无任何权利保留，可随意使用

它笔画粗细均匀、结构更"方正"，但复杂字（巢 / 汉 / 徽 / 籍）容易糊成一团，
拉丁字母和数字也比宋体宽，所以最终选了宋体那份。

## 5. 编辑器图标（HackerNoon Pixel Icon Library）

`.editor/ui.html` 里那 20 个像素图标来自 **HackerNoon Pixel Icon Library**：

- 官网 <https://pixeliconlibrary.com/>，仓库 <https://github.com/hackernoon/pixel-icon-library>
- 许可：官网标 **CC BY 4.0**，仓库里的 `LICENSE` 写的是 **MIT**
  （Copyright (c) 2023 HackerNoon）。两种都要求署名，所以编辑器侧栏底部
  **固定挂了一行**「图标：Pixel Icon Library by HackerNoon（CC BY 4.0）」，别删。
- 取的是 `icons/SVG/regular/` 里的 20 个（不是 solid 那套），画在 **24×24 网格**上，
  一个「像素」正好 1 个单位。
- 用法：整份 sprite 内联在 `ui.html` 里（`<svg id="sprite">` + 20 个 `<symbol>`），
  页面里用 `<svg class="ico"><use href="#ico-xxx"/></svg>` 引用，颜色跟着 `currentColor` 走。
  **内联而不是外链**，编辑器断网也能用。

用到的 20 个：`plus`(新建) `eye`(预览) `external-link`(线上站) `check`(构建检查)
`upload`(发布) `cog`(设置) `link`(友情链接) `grid`(小按钮) `code`(脚本管理)
`calendar-alt`(日历/插入日期) `bold` `italics` `comment-quote`(心声) `pencil-ruler`(宽度)
`expand`(应用宽度) `image`(插图) `thumbtack`(草稿) `save` `trash` `refresh`。

> 整倍缩放那条规矩见「使用与维护」里对应小节：
> `图标(CSS px) × DPR = 24 的整数倍`，跟站里点阵字体是同一个道理。

## 换成别的字体要注意什么

1. **必须落在 12px 栅格上**，否则「字号 × DPR = 12 的整数倍」这条规则会失效，
   方块立刻发虚。检查方法：所有坐标都是 `unitsPerEm / 12` 的整数倍，且没有曲线段。
2. **度量要跟宋体对齐**，不然同一行里混排会让行高跳。宋体点阵的 `hhea` 是
   `1280 / -256`（em = 1536），对应 83.3333% / 16.6667%。MS Gothic 和 Mona 都用
   `ascent-override` / `descent-override` 对齐到了这个值。
3. **不能加粗**。实测加粗后点阵边缘的灰阶像素占比从 39% 涨到 52%，方块全糊。
   站点在点阵模式下把 `font-weight` 统一压成 `normal`，用字号表达层级。
4. **字体文件走相对路径**。CSS 发布在 `/xxx/css/retro.css`，用 `../fonts/` 指过去；
   用 `absURL` 的话在 `127.0.0.1` 和 `localhost` 之间切换会变成跨域请求，
   而字体是 CORS 模式加载的，跨域又没有 `Access-Control-Allow-Origin` 会被直接拒掉。
