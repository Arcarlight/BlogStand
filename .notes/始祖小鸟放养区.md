# 始祖小鸟页面的放养区（/tobitaiaaken/ 底部那一格）

「想要飞的始祖小鸟」那一页最底下、**留言板上面**多了一格放养区：从繁盛之森里
随机来 1~2 位（符利根 / 庞特斯 / 德蕊艾德 / 以格尼斯 / 虹星 / 桃桃加），
在草皮上来回走、时不时蹦一下；**点一下可以摸他**，他会换个表情说一句话；
平时过一会儿也会自己嘟囔一句。背景沿用侧栏那只放养区的天空（晴天蓝天白云、
雨天雨丝、夜里星星月亮）。

- 同一个标签页里翻页不会换人（存在 `sessionStorage`），关掉标签页重新打开才会重抽。
- **一次只上 1~2 位**；庞特斯 / 德蕊艾德 / 以格尼斯是幼驯染三人组，
  **一次最多出现其中一位** —— 抽签抽的是「名额」，抽中三人组再从三只里随机挑一只。
- 角色大小**按游戏里的比例**：虹星（64 像素的走图格）最大，桃桃加（48）中等，
  三只小鸟（32）最小 —— 和页面上 CHARACTERS 那几张立绘的观感一致。

## 二、怎么改

```sh
python tools/build-tbtak.py             # 全量：重拼精灵表 + 索引 + 台词（需要游戏工程在本机）
python tools/build-tbtak.py --talk      # 只重生成台词 JSON（不碰素材，一秒、不联网）
python tools/build-tbtak.py --src D:\别的路径\Graphics    # 素材换地方了
python tools/build-tbtak.py --ascii hoshi   # 把某人的精灵表打成字符画（检查用）
```

⚠️ 跑完记得 `git add -A && git commit && git push`，GitHub Actions 那边会自动发布。

### 1. 换名单 / 加人

编辑 `data/tbtak-pool.toml`：

```toml
[[chara]]
id    = "fliegen"            # 文件名、URL 名（talk/fliegen.json）
name  = "符利根"              # 说话那一格显示的名字
en    = "Fliegen"            # 英文名（跟在种类名后面）
kind  = "始祖小鸟"            # 种类名
walk  = "$WalkFliegen.png"   # Characters 里那张走图
face  = "Actor1.png"         # Faces 里那张表情表
faces = [0, 6, 1, 5]         # 正常 / 笑 / 不耐烦 / 惊醒，填 0~7
group = "trio"               # 幼驯染三人组（互斥）；不写就是各自独立
```

`faces` 的那 4 个数是**表情表里的格子号**：0~3 = 上排从左到右，4~7 = 下排从左到右。
想换表情就用 `--ascii` 或者直接看那张 Faces 图数格子。

加一个新人：往名单里加一条 → 建 `data/tbtak-talk/<id>.toml` → 跑 `python tools/build-tbtak.py`。
（走图和脸图必须在上面那两个目录里找得到，脚本找不到会直接报错，不会生成半张图。）

### 2. 改台词

编辑 `data/tbtak-talk/<id>.toml`，然后 `python tools/build-tbtak.py --talk`。
格式：

```toml
name = "符利根"

greet = [ … ]      # ≥2 条：刚打开页面时说的第一句
pet = [ … ]        # ≥5 条：被摸时说的
pet_more = [ … ]   # ≥2 条（可选）：连着摸第四次起说的
idle = [ … ]       # ≥8 条：平常自己嘟囔
night = [ … ]      # ≥2 条（可选）：深夜（22:00–06:00）说的
```

硬规矩（脚本会拦）：

- **一句不超过 40 字**（说话那一格很宽，但太长会换行换得难看），建议 8~24 字。
- 不要用引号、书名号、括号，也不要写「符利根：」这种前缀。
- **符号要看字体有没有**：站里那三份点阵字体有的（♪ ★ ☆ ♥ ← → 等）随便用，
  没有的会被拦下来（判断方式和宝可梦那边是同一份代码，见
  `.notes/宝可梦放养区.md` 的「想加一个字体里没有的符号」）。
- 同一只内部、以及**六只之间**都不许有重复句（脚本全量比对，撞句直接报错）。

> 2026-09-15 第一版：六只各 20 句（greet 2 / pet 5 / pet_more 3 / idle 8 / night 2），
> 合计 120 句，无重复。

### 3. 开关和调试

| 开关 | 位置 | 作用 |
| --- | --- | --- |
| `tbtakPasture` | `content/tobitaiaaken.md` 的 front matter | 去掉就整格消失（其它页面想加就在那页加上这一行） |
| `pkmnWeather` | `hugo.toml` `[params]` | 关掉「查天气」，这一格也不发任何第三方请求 |
| `?tbtak=fliegen,hoshi` | URL | 强制上场的是谁（逗号分隔的 id，最多两位） |
| `?tbtak=random` | URL | 强制重抽（无视这一标签页记住的那份） |
| `?pkmn-weather=rain` | URL | 只看背景：把天气固定住（`clear…thunder`） |
| `?pkmn-time=night` | URL | 只看背景：把时段固定住（`dawn/day/dusk/night`） |
| `?tbtak-debug=1` | URL | 暴露 `window.__tbtak` |

`?tbtak-debug=1` 之后在控制台里：

```js
__tbtak.state()               // 现在场上有谁、走到哪、在做什么
__tbtak.pick()                // 只跑一次抽签（纯函数，用来验证三人组互斥）
__tbtak.say('hoshi','试试')    // 让某位说一句（调试用）
__tbtak.pet(0)                // 摸第 0 位
__tbtak.sky()                 // 背景状态；__tbtak.sky('snow','night') 现场换天气
```

## 三、素材是怎么来的

游戏里的走图是 RPG Maker 格式：**一行 3 帧、共 4 行**，四行依次是
「朝下 / 朝左 / 朝右 / 朝上」，3 帧是「左步 / 站住 / 右步」。
（已核对：第 0 行的确是面向访客的正脸 —— 桃桃加那一行能直接看到眼睛和腮红；
第 1 行朝左、第 2 行朝右，互为镜像。）

`tools/build-tbtak.py` 取走图里需要的三行（下 / 左 / 右，不用朝上那行），
**九帧一起做一次并集裁切** —— 这样帧与帧之间、方向与方向之间的相对位置
（脚踩的那条线）全部保住，再按底边对齐拼进精灵表：

```
第 0 行  朝下走（3 帧：左步 / 站住 / 右步）
第 1 行  朝左走（3 帧）
第 2 行  朝右走（3 帧）
第 3 行  影子（只有第 0 列，脚本按身体宽度画的硬边点阵椭圆 —— 游戏里没有影子）
第 4 行  脸图 96×96（列号见索引里的 f.c：正常 / 笑 / 不耐烦 / 惊醒）
```

每一格是 `cw × ch` 美术像素；因为脸图是 96×96，所以格子统一是 96×96，
走图那一行按底边居中放进去 —— **角色本体的像素大小原样保留**，
所以六只在页面上的大小比例和游戏里一致（虹星 58×55、桃桃加 40×42、
符利根 30×27、德蕊艾德 24×22、庞特斯 20×25、以格尼斯 20×29）。

### 页面上的放大倍数

和侧栏那只同一个规矩：**美术像素 × 整数 = 设备像素**。

- 倍数 `S = max(1, round(devicePixelRatio × 1.5))`：100% 缩放下是 2、150% 是 2、200% 是 3。
- 画布 `width/height` 用设备像素，CSS 尺寸 = 设备像素 ÷ dpr，位置吸到整设备像素。
- 走动是「一格一格」的（RPG Maker 走图本来就是一格一格的），每帧 190 ms。

实测（无头 Chrome 逐块统计）：100% 下每个角色画布都是 **2×2 同色块、0% 不对齐**；
200% 下是 **3×3、0% 不对齐**。

## 六、已知边界

- **重新生成精灵表需要本机的游戏工程**（`D:\MakingGame\TobenaiArchen\Graphics`），
  而且要有 Python + Pillow。换机器用 `--src` 指过去；只改台词用 `--talk`，什么素材都不需要。
- `static/tbtak/index.json` **会被内联进那一页**（这样选中之后马上就能下精灵表），
  约 1.2 KB。不想背就把 `tbtakPasture` 去掉。
- 每次访问实际只多拉 **1~2 张精灵表（5~13 KB）+ 1~2 个台词 JSON（各 2 KB）
  + 1 张草地贴图（0.3 KB）+ 1 张图标表（1.7 KB）**，天空是画出来的、不加载图片。
- 一个标签页里只上 1~2 位（翻页不换）。想换：关掉标签页重开，或 `?tbtak=random`。
- **没有睡觉那套**（侧栏那只才有）：这一格的角色不会睡，深夜只会说 `night` 那几句。
- 夜里画面不会把角色压暗（和侧栏那只一样，只有背景变暗）——
  想加的话是在角色画布上 `source-atop` 叠一层半透明夜色，点阵不会糊（还没做）。
- 系统里开了「减少动态效果」时：站着不动，但照样说话、天也照画（不会飘云落雨）。
- 页面切到后台标签页时逻辑暂停（`document.hidden`），切回来不会「跳」一大步。
- 无 JS（或者素材没生成过）时：这一格要么整块不出现（`index.json` 不存在时 partial 直接跳过），
  要么退回 CSS 兜底（草地贴图 + 浅蓝底、没有角色）。

## 七、当时验证过什么

**2026-09-15 第一版（始祖小鸟页面放养区上线）**

- 素材：六只的走图 + 脸图都能从本机工程取到；表情槽位按 `faces = [0,6,1,5]` 这类配置挑，
  一样的槽位会自动合并（桃桃加只有 3 个不同表情，所以 `nag` 和 `wake` 是同一张）。
- 精灵表：六只各 5.4~13.3 KB，格子统一 96×96，角色本体像素大小和游戏里一致。
- 台词：六只各 20 句，共 **120 句**，逐句过了长度 / 字符 / 重复校验（六只之间也没有重复句）。
- 抽签：连抽 300 次 —— 一次 1 位 152 次、2 位 148 次（约各半），
  **三人组同时出现 0 次**，两个名额都是独立角色的 72 次（符利根+桃桃加这种是允许的）。
- 渲染：100% / 200% 两档、一位 / 两位两种情况，每个角色画布逐块统计都是
  **0% 不对齐**（100% 是 2×2 同色块、200% 是 3×3），画布设备像素数 = 格子 × S。
- 交互：点草皮上某一位 → 台词从招呼换成被摸那句（「今天也要飞起来。」→
  「唔……翅膀还没长齐呢。」）、脸图换成笑的那张（画布里有 5605 个不透明像素）。
- 走动：两秒内位置在变、朝向在 left/right/down 之间切、跳跃高度非零（4.7 美术像素）。
- 兜底：关掉 JS 时围栏退回草地贴图 + 浅蓝底、没有角色画布、标题还在；
  `prefers-reduced-motion` 下两位的位置在 2.2 秒里一个像素都没动。
- 页面位置：截图确认这一格正好在正文和**留言板上面**；
  侧栏那页（`/tobitaiaaken/` 本来就把侧栏藏了）不受影响。
- 顺带把天气链路抽成 `static/js/pkmn-weather.js`（两个放养区共用），
  侧栏那只改完之后重跑了全套检查：4 档 DPR 都是 0 个坏块、草地逐像素一致、
  无 JS 兜底、减少动态效果、雷电会闪、六个页面都能拿到天气（thunder）。
- 控制台报错：0 条（只有 ipwho.is 限流的 429，那是定位服务，本来就排了 geojs 兜底）。
